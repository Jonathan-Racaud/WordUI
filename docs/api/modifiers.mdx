Modifier words act on the widget at the stack top. They follow **Rule B**: always write the
widget word first, then its modifiers. This is the concatenative discipline — the modifier
sees whatever widget is on top and modifies it in place, which means closed containers compose
with modifiers for free.

## Layout modifiers

### Padding

```
( widget float -- widget )
```

```beef
VStack(scope () => { ... }); Padding(8);
```

Applies uniform padding to the stack-top widget. Padding is a universal `Widget` field;
every widget participates in flow layout.

### Spacing

```
( widget float -- widget )
```

```beef
HStack(scope () => {
    Button("A");
    Button("B");
}); Spacing(4);
```

Sets the gap between children in a stack container. Requires the widget to have a
`StackLayout` component (Component bag) — applying `Spacing` to a `Label` errors with:
`"Label has no StackLayout — Spacing does not apply to it"`.

## Text modifiers

These target the `TextStyleProperty` in the Property bag.

### TextColor

```
( widget color -- widget )
```

```beef
Label("Warning"); TextColor(.Red);
```

### FontSize

```
( widget float -- widget )
```

```beef
Label("Title"); FontSize(24);
```

Sets the font size in pixels.

## Identity

### Key

```
( widget int -- widget )
```

```beef
Label(scope:: $"Item {i}"); Key(i);
```

Sets a stable identity hint on the stack-top widget. `KeyAssign` feeds this hint (when `>= 0`,
e.g. a list-item index) into each widget's `StableKey` path hash as its discriminator instead
of the sibling ordinal, so dynamic children keep a stable identity for the persistent
[`InteractionStore`](/concepts/interaction-pipeline) across rebuilds.

## Cross-axis alignment

These words set the `CrossAlign` field on a `LayoutHint` property (Property bag,
get-or-create pattern). They determine how a child is positioned perpendicular to the
stack's main axis.

| Word | `CrossAlign` | Effect |
|---|---|---|
| `Center()` | `.Center` | Center in the cross axis |
| `AlignStart()` | `.Start` | Align to the start of the cross axis |
| `AlignEnd()` | `.End` | Align to the end of the cross axis |
| `AlignStretch()` | `.Stretch` | Stretch to fill the cross axis (default) |

```beef
VStack(scope () => {
    Label("Centered"); Center();
    Label("Left"); AlignStart();
    Label("Right"); AlignEnd();
});
```

## Sizing constraints

These set sizing constraints on the `LayoutHint` property.

| Word | Description |
|---|---|
| `Width(SizingConstraints)` | Set width constraint |
| `Height(SizingConstraints)` | Set height constraint |
| `FixedSize(float wh)` | Set both width and height to `Fixed(wh)` |
| `FixedSize(float w, float h)` | Set width and height independently |

`SizingConstraints` is a discriminated union:
- `.Unconstrained` — natural size
- `.Fixed(float)` — exact pixels
- `.Min(float)` — at least this size
- `.Max(float)` — at most this size
- `.Percent(float)` — fraction of parent (0.0–1.0)
- `.Range(float min, float max)` — between min and max

```beef
Button("OK"); FixedSize(120, 40);
```

## Interaction state

Both words below always run their body at build; the enclosed styling words record a
field-level style patch that the draw pass applies only while the state is active. See the
[Interaction Pipeline](/concepts/interaction-pipeline) for the full model.

### IfPressed

```
( widget delegate -- widget )
```

```beef
Button("+"); {
    TextColor(.White);
    IfPressed(scope () => {
        Fill(.(120, 120, 120, 255));   // applied while pressed
    });
    OnClick(new => { mCount++; Invalidate(); });
}
```

Records the enclosed styling as a patch that applies while the stack-top widget is pressed.
Built on `IfActive<PressState>`, which get-or-creates a `PressState` property (Property bag);
at draw, `StyleResolve` checks `Store.IsPressed(widget.StableKey)` and blends the patch over
the base. Press requests a repaint, not a rebuild.

### IfHover

```
( widget delegate -- widget )
```

```beef
Button("+"); {
    IfHover(scope () => {
        Transition(150, scope () => { Fill(.(90, 90, 90, 255)); });   // fades in on hover
    });
}
```

Same mechanism as `IfPressed`, gated on hover (`IfActive<HoverState>` →
`Store.IsHovered(key)`). Hover is hit-tested on pointer motion and resolved at draw, so
entering/leaving repaints without flicker or a per-motion rebuild.

### Transition

```
( int delegate -- ) · ( int Easing delegate -- )
```

```beef
IfHover(scope () => {
    Transition(200, .Spring, scope () => { Fill(.Blue); });
});
```

Marks the fields recorded inside its body as animated over `ms` milliseconds (default curve
`.EaseInOut`; overload takes `Linear` / `EaseInOut` / `Spring`). The animation runs off a
clock in the persistent store, so it survives a rebuild and keeps the frame loop ticking
until it settles. Outside a state body it is a transparent pass-through. Only animatable
fields interpolate — `Radius` currently applies instantly even inside a `Transition`.
